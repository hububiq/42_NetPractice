# 42_NetPractice
This project has been created as part of the 42 curriculum by hgatarek


!!!! DESCRIPTION !!!!

This activity is a general practical exercise designed to introduce to the basics of computer networking i.e. how to configure IP addresses, connect devices through a router, how to set IP and masks when the switches come to play, what's range, what's subnet, what's the role of a gateway for external networks.

!!!! INSTRUCTIONS !!!!

To start netpracticing, downdload file attached to the project's page.
Extract them wherever you want.
Rund index.html. It should open in a browser.
You can put your login in the field to use your configuration, choose between training and evaluation mode.
Now you see, respectively, first non-functioning network diagram (level1) or random level from range 6-10.

"Check again"
To verify if your configuration is correct or not.

"Get my config"
After you solve the puzzle and reach every Goal from the level, you are eligible to get your config in .json format by pressing "Get my config.". I needed 10 levels configs to be pushed to 42 repository for evaluator to pull it.

"Next level"
Once configuration is correct and Goal highlighted in green color, this button will pop up to proceed to next level.
